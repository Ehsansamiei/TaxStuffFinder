# 🧾 Stuff-Finder – Iranian Tax Data Explorer

*Stuff-Finder** is a Blazor-based web application designed to help users easily search through Excel files containing tax rate information for goods and services in Iran.  
The project focuses on clean architecture, reusable components, and a smooth user experience.

---

## 🚀 Features

### 🔍 Excel Data Search
Quickly search through Excel files that include tax percentage data for different goods and services.  
The search system is optimized to handle large datasets efficiently.

### 🔗 Shareable Query URLs
Each search generates a unique, shareable URL.  
You can simply send the link to someone else, and they’ll see **the exact same results** you did — no need to re-enter the search!

### ⚙️ Component-Based Architecture
The entire UI is built with modular, reusable Blazor components.  
Every element — from dropdowns to pagination — is organized and styled with clean, modern design principles.
